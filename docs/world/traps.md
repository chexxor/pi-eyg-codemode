Append-only. One entry per trap, three lines at most, naming the wrong path taken
and the command that proves the trap still applies. Entries dated 2026-11-16 or 2026-11-15
were first seen while this package lived in `/home/chexxor/Git/eyg-lang`; their verify
commands are written for this tree.

Quote the website when you can load it; the copies are for a session that cannot, and comparing one against its page is the fix. verify: `grep -q 'Copied from the language workspace on 2026-11-18' guides/install_prebuilt.md && grep -q 'https://eyg.run/guides/install-a-prebuilt-binary' README.md`
